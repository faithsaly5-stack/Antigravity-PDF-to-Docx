# ۱. مقدمه و مبانی نظری

در این آزمایش، رفتار تعادلی کمپلکس آهن (III) تیوسیانات در محیط آبی مورد مطالعه قرار می‌گیرد. این کمپلکس دارای رنگ قرمز خونی مشخص است و واکنش تعادلی تشکیل آن به صورت زیر بیان می‌شود:

$$
\text{Fe}^{3+} + \text{SCN}^- \rightleftharpoons \text{FeSCN}^{2+}
$$

ثابت تعادل واکنش فوق بر اساس غلظت‌های تعادلی گونه‌ها به کمک رابطه زیر تعیین می‌گردد:

$$
K_{eq} = \frac{[\text{FeSCN}^{2+}]}{[\text{Fe}^{3+}][\text{SCN}^-]}
$$

طبق قانون بیر-لامبرت، جذب نوری یک محلول رنگی در طول موج بیشینه ($\lambda_{\max} = 447\text{ nm}$) با رابطه $A = \varepsilon b C$ متناسب است. در این رابطه $\varepsilon$ ضریب جذب مولی، $b$ طول مسیر عبور نور در سل کووت (برابر با $1.00\text{ cm}$) و $C$ غلظت کمپلکس رنگی است.

> [!NOTE]
> رعایت اصول کالیبراسیون دستگاه اسپکتروفتومتر با محلول بلانک (آب مقطر یا نیتریک اسید $0.1\text{ M}$) قبل از هر سری اندازه‌گیری الزامی است.

# ۲. محاسبات و رفتار دوزنجیره‌ای کاتیون‌ها و آنیون‌ها

هنگام حضور هم‌زمان یون‌های مزاحم نظیر $(\text{Cl}^-)$، $(\text{SO}_4^{2-})$ یا $(\text{NO}_3^-)$، تعادل واکنش تحت تأثیر اثر یون مشترک و قدرت یونی محلول قرار می‌گیرد. مقدار غلظت اسید با نماد لاتین به صورت $M(\text{acid}) = 0.120 \pm 0.010\text{ mol/L}$ ثبت شده است تا از وارونگی پرانتزها در خروجی نرم‌افزار جلوگیری گردد.

> [!WARNING]
> احتیاط: محلول هیدروکلریک اسید $(\text{HCl})$ و سدیم هیدروکسید $(\text{NaOH})$ خورنده هستند. در تمام مراحل کار باید از دستکش و عینک محافظ استفاده شود.

## ۲.۱. کد پایتون محاسبه ثابت تعادل

برای پردازش محاسباتی داده‌های جذب سنجی و به دست آوردن ثابت تعادل، اسکریپت پایتون زیر توسعه داده شده است:

```python
import numpy as np

def calculate_keq(absorbance: float, epsilon: float, fe_initial: float, scn_initial: float) -> float:
    """محاسبه ثابت تعادل واکنش بر اساس قانون بیر-لامبرت"""
    # غلظت کمپلکس در تعادل
    fe_scn_eq = absorbance / epsilon
    
    # غلظت تعادلی واکنش‌دهنده‌ها
    fe_eq = fe_initial - fe_scn_eq
    scn_eq = scn_initial - fe_scn_eq
    
    # محاسبه ثابت تعادل
    keq = fe_scn_eq / (fe_eq * scn_eq)
    return keq

abs_sample = 0.485
eps = 4700.0  # L/(mol.cm)
print(f"K_eq = {calculate_keq(abs_sample, eps, 0.002, 0.002):.2f}")
```
